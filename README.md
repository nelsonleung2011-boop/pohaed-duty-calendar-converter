# pohaed-duty-calendar-converter

A **mobile-first, 100% client-side** static web app that turns the POH AED *One-Page Duty* `.xlsx`
roster into a personal, colour-coded monthly calendar. It runs entirely in the browser — no backend,
no build step, no upload. Deploy it straight to GitHub Pages.

Upload → pick a doctor → see their month → download a styled Excel calendar or an `.ics` file.
Nothing is displayed until you explicitly choose a doctor.
